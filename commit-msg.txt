fix(package): pack the new extension module

`verify-package` walks the packed file closure from `extensions/nmg.ts` and fails when a relative
import is not itself packed. The new `.pi/extensions/nmg/ooo-round.ts` is reached through the
extension index but was not in `files`, so both the static contract and the Node 22 job failed with
"packed Pi extension has missing runtime imports" — a real packaging gap that CI caught and that
local runs missed, because the gate needs `node_modules` and the branch was not where I had them.

Verified locally with the gate itself: `npm run package:check` now reports
`package closure ok: 163 runtime files, 250 packed files`.

The file imports only node builtins, so no further pack entries are needed.
