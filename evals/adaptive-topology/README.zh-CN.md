# 自适应拓扑消融

[English](README.md) | [简体中文](README.zh-CN.md) · [术语](README.terms.yaml)

运行确定性的留出关系与路由实验：

```powershell
npm run eval:adaptive
```

每个 case 创建两个语义正交的节点。查询只标识入口节点，而所需证据在另一个节点里。实验比较扁平检索、固定无链接图，以及一个被接受的共同检索提议。它还比较在标签之前的启发式路由器与在显式有用节点标签之后的既有框架无关在线路由器。

除非自适应图召回优于固定图、带标签路由优于启发式路由，且提议精确率在受控负载上为 100%，该命令失败。这是机制／消融测试，不是关于自然对话质量的声称。

2026-07-19 的本地 30 case 运行产生扁平／固定／自适应召回 0%/0%/100%、启发式／带标签路由准确率 0%/100%，以及 100% 提议精确率。P50 检索延迟约 0.36/0.78/1.10 ms。此处没有给出运行工件路径，因此无法仅凭本 README 独立复现这些历史数字。这种极端分离是刻意设计的：每个留出 case 恰好需要由重复的有用共同检索标签所提供的那条关系。
