# 邻接：是内容有用，还是关系有用？— 2026-10-23

[English](locomo-adjacency-rendering-2026-10-23.md) · [术语](locomo-adjacency-rendering-2026-10-23.terms.yaml)

证据边界：单一读者/裁判模型家族、每臂单次运行，且只取"位置可能改变答案"的题。这是子集上的答案阶段测量，不是基准分数。

## 问题

会话邻接在时间与单跳两类上提升了覆盖率（+11.7pp，21胜4负）。被救回的话轮有一半以代词开头，于是有两种竞争解释：

1. **内容有用**——邻接只是"够得着那段文字"的通道；
2. **关系有用**——读者需要那一轮被放在它所承接的记录旁边。

## 方法

四个臂携带相同记录，只有放置方式不同。四条臂的每一行都带会话日期：LoCoMo 的 prompt 要求读者使用时间戳，而记录下来的页面没有日期；不补的话时间类题的"答对/答错"无法区分。

| 臂 | 记录 |
| --- | --- |
| `page` | 记录下来的 20 条页 |
| `tail` | 页 + 追加的会话邻轮，接在末尾 |
| `anchored` | 页 + 每个邻轮紧接其 anchor 之后（按会话顺序） |
| `placebo` | 页 + 同样条数、但取自页从未触及的会话 |

范围：只取"标注证据轮在页内缺失、却出现在追加邻轮里"的题——位置能改变答案的题。时间＋单跳类 145 题中 23 题，多跳 279 题中 84 题。官方 LoCoMo 答案与判题 prompt，temperature 0，关闭 thinking。

## 结果

时间＋单跳（n=23，每臂 23 条已判）：

| 臂 | 正确 | 准确率 |
| --- | ---: | ---: |
| page | 10/23 | 43.5% |
| tail | 21/23 | **91.3%** |
| anchored | 21/23 | **91.3%** |
| placebo | 12/23 | 52.2% |

| 配对 | 胜/负/平 | 精确 p |
| --- | --- | ---: |
| tail 对 page | 11 / 0 / 12 | 0.00098 |
| anchored 对 page | 11 / 0 / 12 | 0.00098 |
| **anchored 对 tail** | **0 / 0 / 23** | — |
| placebo 对 page | 2 / 0 / 21 | 0.5 |

多跳（n=84，每臂 82–83 条已判）：

| 臂 | 正确 | 准确率 |
| --- | ---: | ---: |
| page | 51/83 | 61.4% |
| tail | 69/82 | **84.1%** |
| anchored | 65/82 | 79.3% |
| placebo | 53/83 | 63.9% |

| 配对 | 胜/负/平 | 精确 p |
| --- | --- | ---: |
| tail 对 page | 19 / 1 / 61 | 0.00004 |
| anchored 对 page | 17 / 2 / 62 | 0.0007 |
| **anchored 对 tail** | **3 / 6 / 72** | 0.51 |
| placebo 对 page | 5 / 3 / 75 | 0.73 |

## 解读

- **价值在补回的内容**：追加链规则选出的邻轮，两个范围合计胜 30 负 1。
- **价值不在"上下文更多"**：追加同样条数、但取自无关会话，几乎无变化（2胜0负、5胜3负）。
- **价值不在放置**：把邻轮贴到各自 anchor 之后，23 题上完全相同，多跳上还略差（3胜6负，p=0.51）。代词那条担心没有通过答案阶段：邻轮的指代对象本来就在页内，位置不影响。
- 直接后果：产品现有的 `expandChains` 形状——**追加在末尾、有界**——就够用；不需要"贴 anchor"的渲染，也不需要顺序元数据进入 prompt。

## 注意

- 绝对准确率来自每臂单次运行。同一批 prompt 重跑 page 臂得到 12/23 与 10/23（temperature 0），所以单次运行的绝对差有几道题的噪声；**同一轮内的配对比较才是承重证据**。
- 单一裁判、与读者同模型家族、无人工抽查。多跳侧每臂有 1–2 条 judge 输出无法解析而被丢弃。
- "informative" 子集是按机制起作用的位置挑的，因此这些准确率不等于整套题的准确率。
- token 用量：回归 234,862 prompt tokens，多跳 854,287，服务商未报告缓存命中。
