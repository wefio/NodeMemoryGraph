## 协议

完整 Agent 计划已经列出原子检查并对相同命令去重。本实验把构建与打包检查保留为串行屏障，以最多三个异步 npm 进程运行相邻的已批准静态检查，然后在静态组之后运行 `test:product`。每项检查保留自己的结果，整次运行只保留一个 150 秒时限。一个调度器测试检查并行执行、屏障、声明顺序证据与失败归属；一个真实 npm 测试检查异步退出归属。

在 Windows、Node v24.19.0 上运行 `rtk npm run agent:verify -- --full`。下表把串行基线标为 100.0 秒，而[原子检查实验](full-gate-atomic-checks-2026-09-23.zh-CN.md)最后一行是 107.4 秒。本记录未指明 100.0 秒这一行的原生 run 或输入快照；较早把它归为最后一次运行的说法仍未解决。
