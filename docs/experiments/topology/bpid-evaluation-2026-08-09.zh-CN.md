## 问题

一个廉价、无模型的 candidate 生成器能否在不隐藏大多数真实身份匹配的前提下缩小节点对搜索空间，以及 NMG 当前的高置信 gate 是否足够精确，以授权无人值守的物理合并？

## 数据集与协议

`npm run eval:topology:bpid` 使用随 _BPID: A Benchmark for Personal Identity Deduplication_（EMNLP 2024）发布的官方 BPID matching split：10,000 对合成 profile，由训练过的标注者独立标注，其中包含 4,333 个匹配与 5,667 个非匹配。源归档在 [Zenodo](https://zenodo.org/records/13932202) 上以 Apache-2.0 发布；论文与数据集说明可从 [ACL Anthology](https://aclanthology.org/2024.emnlp-industry.40/) 获得。

Lab evaluator 计算姓名、email、电话、地址与出生日期的相似度，并将其组合成一个未校准的 blocking score。它不是概率，也不是产品阈值。它报告完整的阈值曲线，因此不会被静默采纳某个 benchmark 调出来的单一 cutoff。它不调用 LLM 或 embedding 模型。

在一个有界恢复探针中，三个标注为匹配与三个标注为非匹配、且得分至少 `0.98` 的样本被物化为彼此独立的 NMG entity 节点。每个候选节点对接收五次构造出来的 proposal observation，而不是五份独立来源的身份确认；随后经过真实的 automatic-merge 评估，执行物理合并，并立即用其 journal 回滚。这有意测量的是可恢复性，而不是明知负样本仍去合并是否可接受。

在 `0.98` 处，241 对节点对通过：222 个匹配与 19 个非匹配。六个有界合并／回滚探针全部恢复了原有的记忆归属与节点 ID；其中三个是刻意选取的 false positive，也被恢复。

## 解释

该廉价分数只在作为 **blocking／candidate 生成信号**时有用。它只能在几乎不排除节点对空间的情况下保住几乎所有匹配。把它收紧到使候选池缩减约 98%，会摧毁 recall，且入选节点对中的非匹配比例仍为 7.88%（19/241）。这不是实测的无人值守错误合并率；本探针没有物理合并大多数入选节点对。若干 hard negative 共享看似决定性的标识（email、电话、姓名或出生日期），而另一个字段与之冲突。因此：

- 相似度可以提名一个有待语义审阅的有界节点对；
- 高相似度值不得被解释为已校准的身份置信度；
- 当 NMG 当前 automatic merge gate 的置信输入来自该 blocker 时，它不足以用于无人值守的合并 actuation；
- 显式冲突检测、单独验证过的语义 judge，以及真实使用中的错误成本仍然必需；
- journal 化回滚限制了损害，但并不能使错误合并变得无害，因为错误合并后的状态可能已经影响过某个 Agent 的回答。

BPID 是合成、按节点对标注的数据集，而不是自然共存 NMG 节点的在线流。它补上了缺失的 hard-negative／candidate 审计，但并未确立生产精度。无人值守的身份变更仍然关闭。
