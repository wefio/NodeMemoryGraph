# 复用既有检索事件作为低成本召回信号

[English](passive-recall-signals-2026-10-15.md) | [简体中文](passive-recall-signals-2026-10-15.zh-CN.md) · [术语](passive-recall-signals-2026-10-15.terms.yaml)

## 问题

会话试点能否在不增加逐回合判官、诊断 prompt、RPC 或第二个运行时记录器的前提下，
取得弱检索动作观察？目标是在满足充分召回约束下的最小总成本，
而不只是把成本从一个机制搬到另一个机制。

## 方法与来源

这是一次回顾性的只读可行性检查，不是前瞻性的质量或成本对照。被观察的实现是
`b854b413ac5e29cc0a81456b9bed9430aa6652c6`。

既有 [`NmgService`](../../../src/cli/service.ts) 检索路径会为普通检索调用
`#recordRecallInstance()`。[recall-instance owner](../../../src/lab/recall-instance.ts)
已经记录 `kind`、`sessionId`、`trigger`、`activeGraphId` 与有界候选。
观察已记录的显式检索动作不需要新增生产者。

分析读取既有 `<NMG_DATA_DIR>/recall-instances.jsonl` 的固定前缀，过滤会话
`01a12a62-bbe4-76b0-a742-e748dfa0cf0e`，只输出计数。查询文本与候选陈述都不进入本报告。
对选中的图 ID 检查既有标签条目；不生成也不写入任何标签。

- 测量时间：`2026-10-15T07:15:41.402Z`。
- 来源前缀：3,564,300 字节；之后的并发追加被排除。
- SHA-256：`d0a741ace8c2a2dd228ec11e1fb033fbded51cb6e09e7ad7059449433e29c0e0`。
- 选中时间范围：`2026-10-11T09:56:06.881Z` 至 `2026-10-15T06:57:44.790Z`。
- 本地派生收据：`.nmg/verification/passive-recall-trial/existing-events.json`。
  它不是原始语料的副本。要对着增长的来源重放，必须精确读取记录的字节前缀长度，

## 结果

| 观察 | 计数 |
| --- | ---: |
| 当前会话已记录事件 | 33 |
| `auto` | 14 |
| `explicit` | 19 |
| 图 ID 去重 | 33 |
| 选中零候选事件 | 4 |
| 匹配的既有标签条目 | 0 |
| 被捕获前缀中的坏行 | 0 |

其余 3,039 行因会话身份不同而被排除。受既有 owner 约束，选中捕获最多含八个候选。

`explicit` 事件表示一次未标记 `autoRecall:true` 的检索 RPC 执行了。它不能证明主模型
自行选择了检索：客户端与诊断脚本可以发出同一个 RPC。这些行不计为独立的自然任务。
显式触发的是一条检索查询，不一定等于原始用户消息。

语料缺少用户回合身份与入口门决策。缺少 `auto` 行，或与某条 `explicit` 行时间接近，
都不能证明漏掉入口。内部探针被排除，失败的调用与未产生披露图的调用也不是本次捕获的
完整部分。观察计数既不能给出全部检索的分母，也不能给出漏召回率。既有相关性标签即使存在，
也不能证明检索是否必要。

## 成本边界

单次沙箱读／解析／聚合测得 12.9664 ms。这是进程内墙钟观察，文件系统缓存状态未受控。
它不含工具往返、主模型推理、开发与报告成本。它不是逐回合测量，也不是端到端节省的证据。

本次试点没有新增产品运行时路径、工具定义、prompt、模型调用、检索或后台轮询。
既有捕获仍有序列化、文件 I/O 与存储成本；这些既未被测量也未被移除。
读取与分析其输出同样消耗资源。复用它并不让整个系统免费，也不证明基线已最优。

## 结论与边界

既有显式检索事件可在不增加第二个记录器的前提下用于弱观察。一个隔离的会话观察器原型
通过了 70 项定向机制测试、LSP 诊断为零，但被丢弃而非合并：在有数据缺口证明额外运行时
与维护成本必要之前，它只是重复观察。该原型测试通过不验证本信号有用。
没有交付新的 Lab 模式或操作。

既有的[召回提词能力](../../design/design/progressive-retrieval.zh-CN.md#渐进检索)
在本会话保持暂停。不从这 19 条显式事件学习或晋级任何触发词，也不执行反馈、claim 结果、
分类器、共享服务变更或付费模型评测。复用可行性已建立；入口检测、自然质量与最低总成本
仍未验证。
