# 关键词分层标定：首轮闭环与回退结果

[English](recall-tier-calibration-2026-10-16.zh-CN.md) | [简体中文](recall-tier-calibration-2026-10-16.zh-CN.md) · [术语](recall-tier-calibration-2026-10-16.terms.yaml)


## Question and result

本轮计算的是“指标 → 分布 → 边界 → 层内波动 → 调整并重测”，不是继续修改宿主接线。
结果是：**词汇分数可以形成较紧的统计分档，但本次弱请求代理没有选中分层保留；建议保持 FIFO，不把统计分档升级为运行规则。**
这是首轮离线实验的选择，不是“所有分层都无效”，也不是已经解决了永久／限期层的需求判定。
当前[会话词池规范](../../design/design/progressive-retrieval.zh-CN.md#渐进检索)和默认关闭状态不变。

## Inputs and unit

复用 `.nmg/verification/recall-tier-calibration/` 的一次可增长样本快照：

- 1,370 个候选词；不是冻结的正式词库。
- 294 条用户角色记录中，106 轮满足当前静态 skip、可配对动作代理条件。
- 时间前 74 轮训练，后 32 轮观察；训练有 17 个补搜请求代理。
- 全部 106 轮中，23 轮有直接搜索请求或 codemode 搜索调用语法；15 轮有可提词候选。
- 直接请求不等于成功或真实需要；调用语法更不证明执行。动作未知不混为负例。

没有历史真实 LLM 提词。回放在每个合格来源回合的字面候选中均匀取一词，执行
128 个固定种子方案；下文小数是这些选词代理的平均机会量，不是真实查询数或召回率。
只有来源回合允许入池；不会因词库分数高就直接启用整个词库，自动命中也不续命或自证需要。

候选词和词汇特征来自回顾性快照，未证明它们在历史时点已经可用。时间切分不是无泄漏的前向验证。
宿主 task-anchor 和真实试点租约生灭未重建：回放假定来源通道持续可用、限制每词入池年龄。
因此 FIFO-1h 是影子对照，不是现网共同到期的父租约的完整复现，更不授权自动续租。

## Metric and distribution

先分开比较两个指标，不凭空混权重：

- `mean_token_idf`：对词组去重后的 ICU 组成词，取背景段落 IDF 的算术平均。
  单词 IDF 为 `ln((N+1)/(df+1))+1`，本快照背景 `N=4654`。它衡量词汇区分度，不是需要概率。
- `mean_token_contrast`：既有组成词记忆／背景语料对照特征；缺失者保持未评分，不补零。

背景文档不是“不需要记忆”的负例。1,370 词可算词汇特征，也不意味着此前没有行为观测的词突然有了需要分数。
保留优先方向同时比较正向和反向，不假定“高 IDF → 应该长期保留”。

对正值 IDF 比较 8 个描述模型，对有符号 contrast 比较 5 个。连续模型用 MLE；混合模型多起点拟合、固定方差下限。
正值混合在 log 空间拟合，但 likelihood 加回原尺度 Jacobian。固定 location 不算自由参数。
AIC/BIC 只在同一响应指标内比较，不拿不同指标的数值横比。

| IDF 描述模型 | AIC | BIC | ECDF 最大距离 |
| --- | ---: | ---: | ---: |
| 对数正态 | 4442.980 | **4453.425** | 0.03411 |
| Gamma | 4457.654 | 4468.099 | 0.04334 |
| 三分量对数正态混合 | **4426.665** | 4468.445 | **0.01644** |
| 正态 | 4570.017 | 4580.462 | 0.06949 |

按较偏向简单模型的 BIC，IDF 的描述参考选对数正态；**AIC 会选三分量混合，并非两个准则一致**。
有符号 contrast 的 BIC 参考是三分量正态混合，不强行平移成对数正态。

ECDF/Q-Q 图在私有收据目录 `closed-loop/ecdf-qq.svg` 和 `.png`，尾部仍有偏离。
词组共享组成词、分数有并列、混合有正则化；名义 AIC/BIC 不构成独立样本的确定性证明。
这里不给同样本拟合后未经校准的 KS p 值。负二项适合计数，不直接拟合这些连续 IDF 分数。

## Boundaries, dispersion and feedback

边界按训练来源回合的加权 ECDF 初始化：每个来源回合总权重为 1，在其可提词中均分。
这避免一个含 26 个候选的长输入压过一个只有 1 个候选的短输入。它是采样单位的权重，不是学习到的需要权重。

初始切点概率为 `Φ(-z), 0.5, Φ(z)`，枚举 `z=0.5/1/1.5/2`、两个保留方向、最低活跃档和年龄上限。
四档是本轮试验结构，不是 BIC 推导出的必然层数；并列分数不拆散。

资源约束先明示为工程试用点：新增浅查机会最多取原训练补搜代理量的 25%，
即训练上限 `ceil(17×0.25)=5`，后段按相同每轮比例上取整为 3。
另测 0%、50%、100%。这不是钱或总 token 成本的最优值，也没有写入产品跨回合限额。
当前约束选择只比较 1h 年龄上限；24h 单独作为敏感性假设，不修改或延长实际租约。

选择目标是不加任意收益混合权重：在硬查询上限内最大化代理覆盖，再依次减少无请求代理的调用、总调用和复杂度。
这仍是弱代理目标。**1h 内的 48 个分层组合在训练指标上并列，两个指标和两个方向都在并列集合里，无法据此识别唯一需要指标。**
下表选一个固定代表做后续方差调整，不将其称为数据学出的唯一最佳策略。

### Sigma really feeds the adjustment

代表方案的初始切点为 `3.898966 / 5.094872 / 5.897337`。
计算来源加权的 `Σ(weight_band × sigma_band²)`，再用加权一维四类 k-means 提议收紧边界。
只有该形状损失降低，且相同预算下训练代理覆盖不降、调用和无请求代理调用不增，才接受边界修改。

该轮接受了 `4.059697 / 5.276161 / 6.825952`：
来源加权层内 SSE 从 **3.466663 降到 1.305898，减少 62.33%**。
接受的是几何分档改进，不能从中推导真实需要、时间稳定或上线收益。

| 观察档 | IDF 范围 | 本次词库占比 | 词库层内 σ | 来源加权层内 σ | 影子年龄上限 |
| --- | --- | ---: | ---: | ---: | ---: |
| L0 | `<4.059697` | 9.49% | 0.4026 | 0.3109 | 450s，待观察不触发 |
| L1 | `[4.059697,5.276161)` | 36.72% | 0.3270 | 0.3037 | 900s |
| L2 | `[5.276161,6.825952)` | 39.85% | 0.4219 | 0.3619 | 1800s |
| L3 | `≥6.825952` | 13.94% | 0.9281 | 0.3414 | 3600s |

表中是正向代表；反向候选只是保留次序相反。词数比例不是查询／成本比例；整个词库的横截面 σ 也不是时间稳定性。
年龄梯子 `T/8,T/4,T/2,T` 是明确可撤销的初始假设，不是假装由 σ 估出来的寿命。
总池上限仍取 8；未评分者走基线年龄，存在不可比分数时容量退出用 FIFO，不把缺失当最低分。

## Recalibration and migration control

实施了会话块重采样，并在每个重采样来源回合中均匀抽一候选，处理来源相关性和未知提词选择。
训练的 7 个会话块做 500 次重采样，其中 **52 次没有有效提词来源**，明确记录；有效 448 次。
切点的重采样区间很宽，例如第一个约 `[3.5920,8.0917]`，不支持精确阈值或永久晋级的说法。

初始可试验控制规则为：

1. 累积至少 4 个新弱提词来源才做一次标定；不足时积累到下一次，不清空计数。
2. 新切点超出上一标定的 bootstrap 区间才接受移动；部分更新导致切点逆序则整次保持。
3. 操作滞回需求取“邻档横截面 σ、bootstrap 切点绝对误差 95% 分位”的较大值，
   再以邻近切点间距的 1/4 作操作上限。代表值为 `0.3041 / 0.3041 / 0.3874`。
   **这个操作上限不是把统计区间截短后冒充更高置信。**
4. 个词迁移须连续两个标定周期越过相应滞回带，一次只移动一档；自动命中不续命。
   “4 个新来源、两个周期、1/4 间距”都是初始控制假设，不是已证实的最优常数。

前缀回放实际执行了 53 → 74 → 106 轮：来源数 10 → 12 → 15。
第二轮只有 2 个新来源而保持；第三轮累计 5 个新来源，但新切点仍在旧区间内，继续保持。
候选切点分别约 `4.0927/5.3696/6.8883`、`4.0597/5.2762/6.8260`、`4.0191/5.2161/6.7579`。
这是来源组成变化的控制回放，不是历史词分数的真实时间序列；分数本身取同一回顾快照。

另算了带会话末右删失的 Kaplan–Meier 字面再出现曲线。15 个来源的均匀选词方案平均只有约 2.97 次再出现事件。
它描述字面出现而非需要或退词后自然重学；不能据此拟合真实晋降级马尔可夫链。
本轮没有为凑齐工具清单而上多变量贝叶斯或伪造状态迁移标签。

## Same-budget outcome and adoption

在后 32 轮、相同机会预算 3、128 种提词代理方案下：

| 影子方案 | 平均查询机会 | 覆盖补搜代理 | 无补搜代理的查询 |
| --- | ---: | ---: | ---: |
| FIFO-1h | 1.0000 | 1.0000 | 0 |
| σ 调整后的代表分层 | 0.4766 | 0.4766 | 0 |

更紧的统计分档反而损失代理覆盖。这一回放没有触发容量淘汰，也没有用满查询上限，
没有显示出必须用分层淘汰来换取资源的压力；这不否定未来容量受限场景的分层价值。
只保留直接请求、把纯调用语法行保为动作未知的敏感性检查，得到 93 轮（65/28），8 个可提词来源；
后段两种方案都没有覆盖，训练仍选择 FIFO。这也削弱了把主结果当真实收益的依据。

**本轮建议：不采用这些词汇分数驱动运行时分层，保持当前简单词池。**
初始分层候选、预算和迁移规则保留为 shadow 参数，不冻结词库、不宣称唯一最佳指标，
不设置永久层，不让候选分布模型直接决定需要程度。产品当前没有新增上述预算、TTL 梯子或自动标定。

## Reproduction and verification

本地、含私有输入的完整收据位于 `.nmg/verification/recall-tier-calibration/closed-loop/`：
`calibrate.py`、`test_calibrate.py`、`calibration.json`、`direct-only/calibration.json`、`decision.json` 和图。
来源数据散列、脚本散列、包版本、随机种子和重采样参数都在 JSON 中。该目录不是产品读取的配置。
没有公开记忆正文或用户提示。私有样本不随文档提交；本报告保留方法、数字和取舍，不让私有索引成为规范。

在仓库根目录运行：

```text
python -X utf8 .nmg/verification/recall-tier-calibration/closed-loop/test_calibrate.py
python -X utf8 .nmg/verification/recall-tier-calibration/closed-loop/calibrate.py --incidence .nmg/verification/recall-tier-calibration/turn-incidence.json --scores .nmg/verification/recall-tier-calibration/token-idf-scores.csv --out-dir .nmg/verification/recall-tier-calibration/closed-loop
```

追加 `--proxy-mode direct` 并换输出目录可重做敏感性检查；默认 bootstrap=500、选词方案=128、种子=1729。
运行环境为 Python 3.14.7、NumPy 2.5.2、SciPy 1.18.0、scikit-learn 1.9.0；未安装新依赖。

12 个计算自检覆盖来源权重、并列、缺失、池／查询硬上限、命中不续命、方差修改和滞回等。
实际运行与数据恒等式通过，相关 Python LSP 无诊断。原 `turn-coverage.py` 仅改为可导入共享请求代理，
原默认 CLI 的 cohort、60 个机会量 case 和 21 个预算对照逐项相同。
Python DAP 的 `debugpy` adapter 不可用；不声称有 Python 单步证据。
本轮没有 live 检索、LLM／embedding／付费调用、产品源码或配置变更、试点启用、共享服务重启。
