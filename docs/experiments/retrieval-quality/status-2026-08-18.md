## How to reproduce this historical state

This note records the 2026-08-18 experimental arms. The current product-surface
protocol and supported options are canonical in `evals/retrieval/README.md`;
`--hybrid` was retired when the evaluator stopped exposing benchmark-only search
arms. The preserved product-path example below is not a reproduction of the old four
benchmark-only arms. Use the current protocol owner before any authorized run;
it can start an embedding service or incur generation/provider cost:

```powershell
.benchmarks/bge-venv/Scripts/python.exe evals/omnimemeval/bge_server.py --device cuda
npm run eval:retrieval -- --dataset <datasets>
```

Stores persist in `.benchmarks/retrieval-stores/<dataset>/` and are reused;
summaries were reported persisted too (`membersKey` fingerprint). Valid,
compatible cache reuse can avoid new summary calls; missing/stale inputs or changed
configuration may require regeneration. Persistence is not a zero-LLM-cost guarantee.

## Done since

These dated follow-ups retain historical measurements and then-reported knobs,
not fresh product-default or deployment receipts.

- **Node-summary tier** (2026-08-24): one summary per node built from block
  summaries, hysteresis refresh, node-FTS routing behind block hits. BEAM
  stacked 27.0% → 27.4%; LoCoMo unaffected under that stored layout (≥2-block gate,
  degenerate 1-block nodes). Details:
  [retrieval-quality-node-summaries-2026-08-24.md](node-summaries-2026-08-24.md).
- **Cross-block chain pull** (2026-08-24): after block-member selection, the
  remaining member budget (≤ `leafBlockRoutingMaxMembers`) pulls ±1-hop chain
  neighbors — explicit `memory_chain_edges` plus positional neighbors in
  `memory_chain_members` (needed because eval `chainInjection: "logical"`
  chains carry members only, no edges). BEAM stacked+node 27.4% → 27.7%,
  any@20 65.1% → 80.0%, all@20 26.4% → 39.6%, event_ordering 15.6% → 17.4%
  (any@20 57.5% → 90.0%). Cost: ctx 51.1k → 159.4k chars. Details:
  [retrieval-quality-chains-2026-08-24.md](chains-2026-08-24.md).
- **Activation-gated chain expansion** (2026-08-25): the `expandChains`
  default is no longer whole-chain — members are appended when proximity
  (1/(1+dist to nearest hit)) + query-term overlap + 0.5×importance reaches
  0.5, hard-capped by `chainExpansionMaxMembers` (default: ranked count).
  BEAM: R@20 27.7% → 28.9% (originally called noise; no significance established
  here), ctx 159.4k → 93.9k chars. The detailed report retains about 25.5% of the
  any@20 gain with 39.5% of additional context, or 58.9% of whole-chain total
  context; the earlier ~40% coverage-gain claim conflated denominators.
  Event_ordering falls back to the no-chain level. Constants were reported fixed
  by principle, not benchmark-swept; this is not an independent preregistration receipt. Details:
  [retrieval-quality-chain-activation-2026-08-25.md](chain-activation-2026-08-25.md).

  chains, so these counts do not prove unreachable chains or a universal bound.
  They motivated prioritizing cross-session first-hit work in that sample,
  not a finding that further chain work is universally ineffective.

  next lever is batching several blocks per summary call (amortizes the shared
