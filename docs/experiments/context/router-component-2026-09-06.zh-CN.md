证据边界（2026-10-17 文档审阅）：本带日期记录属于历史研究材料，不是当前 runtime 契约，也不授权运行 provider 实验。本轮未重跑所引实验，未独立复核原始运行产物。

状态：已测量的自定义组件实验；未默认启用。

## 协议

命令：`node --experimental-strip-types evals/controller-shadow/context-probe.ts`。
运行器会新建 `.nmg/context-probe/<timestamp>/`，其中包含 `events.jsonl`、`evidence.json`（渲染后的上下文与来源 ID）与 `report.json`；它拒绝覆盖已存在的事件文件。全程不调用任何 embedding provider、主 LLM 或 LLM judge。

- 数据集：通过既有检索数据集加载器读取本地 LoCoMo `locomo10.json`。
- SHA256：`553cd5a15e25f2ceccc6ed185221eba645080c93e5b91087560a91aa5961f365`。
- 1532 道带证据的问题，实际执行 6128 次上下文动作。
- 按来源用户哈希分区：5 个 train、2 个 validation、3 个 test 组。
- 固定使用自定义词法消息排序；这不是产品 NMG 检索路径。
- 四种动作都在逐题完全相同的来源快照上执行；分配方式是确定性枚举（每个分支概率为 1），不是随机化的自然使用。
- 相同硬包络：4000 个上下文字符，最多一次检索调用。
- `resurface`：取排名第一条消息；`retrieve`：取前五条，按整片段装填。
- 奖励：gold 证据覆盖度，不含主模型答案或下游成功指标。
- 132 参数线性头，学习率 0.01；在 validation 上从 1/5/20 个 epoch 中选择。
- 成本惩罚固定为零；token 数为字符数 /4 的估算，不是 provider 实际用量。
- 历史特征缺失，因为这些问题快照分开处理且没有顺序历史；这不表示同一 owner 的问题在统计上相互独立。

## 结果

validation 选择了一个 epoch；全部 331 个 validation 决策都选择了 retrieve。在 354 道留出问题上：

| 策略 | 证据覆盖度 | 估计上下文 tokens/题 | 动作 |
| --- | ---: | ---: | --- |
| 固定 retrieve | 0.3505885122 | 258.0763 | 354 retrieve |
| 线性路由器 | 0.3505885122 | 258.0763 | 354 retrieve |

全部 6128 行结果都被组件评分器绑定接受，没有行被排除。这验证的是用真实 benchmark 来源数据走通被执行的采集／回放／训练／报告路径，不是外部验证者出具的证明。

## 复核跟进：成本、独立性与持久性

A/B 复核促使我们加入了等待式日志屏障、执行结果指纹、执行器调用下界检查以及本地 append/fsync 试验日志。这些保护的是组件的样本路径，不是生产环境的模型暴露或分布式恢复。来源上下文与 ID 保留在 `evidence.json` 中。

报告现在给出每组行数，而不只是问题总数：train 5 组/3388 行，validation 2 组/1324 行，test 3 组/1416 行。三个 test 组分别贡献 600、324、492 行。那 1416 行动作只代表**三个独立来源单元**，而不是 1416 个独立观测。稀疏分组告警是透明性提示，不是统计功效或启用闸门。

一项仅限 validation 的诊断用固定的示例性动作前 token 估算 `[0,21,200,800]` 与延迟估算 `[0,0,1,10]` ms 扫描成本乘子 lambda；价格为每千 token 计 1、每秒计 1。这些不是实测 provider 成本，也不是拟合出的最优价格。Q 在无惩罚的覆盖度上训练；选择阶段只减一次成本，避免对学习目标重复计费。

| Lambda | validation 决策 | 证据覆盖度 | 估计上下文 tokens/题 |
| --- | --- | ---: | ---: |
| 0 | 331 retrieve | 0.3456493654 | 268.4592 |
| 0.1 | 331 retrieve | 0.3456493654 | 268.4592 |
| 1 | 331 none | 0 | 0 |

这只展示了在所选示例网格上从 retrieve 到 none 的一次离散切换，不是实测最优价格、普遍响应曲线或效用提升。另有一组合成回归测试验证：在 token 或延迟价格下，一次很小的检索边际收益会切换为 resurface，且不改变权限或模型 Q 值。已被查看过的 test 集不会被再次用于调 lambda，也不据此宣称新的独立确认。静态匹配快照在构造上就无法衡量顺序历史；在此处加入历史节点并不能修复这一点。

## 解释与界限

未观察到优于固定规则的收益。这并不意外：只以证据覆盖度为目标不会给 cue 赋予任何价值，反而偏好追加已排序的来源内容。该实验无法支持更大的路由器、循环状态、历史节点注意力、自然任务收敛或默认启用。三个 test 组不构成宽泛的泛化结论。本文不主张显著性，也不主张完整的因果任务收益。

后续的效能实验必须包含模型实际消费的上下文、官方答案评分、端到端匹配预算，以及针对任何历史主张的顺序任务结果。该 test 集现已被查看过；此后据此调参属于探索性工作，不再是另一次独立的留出确认。
