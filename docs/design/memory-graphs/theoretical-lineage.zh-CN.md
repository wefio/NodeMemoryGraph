## 理论沿革

以下比较解释 STG/LTG/AG 的角色，不是阅读前提、实现证明或提升策略。
认知存储不等于 NMG 语义存储。所引材料是保留的设计背景，不是新一次文献核实，
也不宣称覆盖完整。

### Atkinson–Shiffrin 多存储模型：1968

Atkinson & Shiffrin 的感觉／短期／长期模型提供历史结构类比：

| NMG 角色 | 类比 | 边界 |
| --- | --- | --- |
| AG | 有限、受注意控制的工作上下文 | AG 是可变会话图，不是生物缓冲区或单次冻结投影。 |
| STG | 持久整合前的临时信息 | NMG 保存暂定含义，可用 SQLite 持久化。 |
| LTG | 持久语义／情节／程序材料 | 持久不保证容量无限。 |

约 20 秒、7±2 chunks 等人类缓冲数字在此只是未经核实的比较线索，不是 NMG
保留时间或容量默认值。注意与归并为受控接纳提供动机，不证明两者的写入路径精确等价。

### 互补学习系统：McClelland、McNaughton 与 O'Reilly，1995

CLS（Psychological Review 102, 419–457；PMID 7624455）提供快速编码／慢速整合类比：

| NMG | CLS 类比 | 设计用途 |
| --- | --- | --- |
| STG | 快速海马编码 | 将暂定材料与稳定结构分开。 |
| LTG | 较慢皮层整合 | 结构归并前要求证据。 |
| STG→LTG | 系统归并／replay | 机制类比，不自动授予提升许可。 |

干扰风险说明为何把快速观察与较慢结构学习分开。重复共同激活可以提名候选，但不能
单独证明关系或提高稳定性。NMG 还要求独立来源／任务归因及合格结果。原子事实可走
独立的受控即时接纳路径；这是 NMG 规则，不是从 CLS 推出的定理。定期 replay
仍是[开放设计问题](../memory-graphs.zh-CN.md#开放问题)。

### ACT-R / SOAR 认知架构

原比较引用 Laird 的 2022 年论述（arXiv:2201.09305）：有界工作缓冲持有当前检索，
陈述记忆保存事实与经历，程序记忆保存技能。类比的是 AG 的有界工作角色。
AG 可跨回合变化，不可变投影修订只选择某次检索／披露面；把整个 AG 称为查询投影
会混淆两种生命周期。

### 现代 Agent 记忆系统：工程比较

记录中的 MemGPT/Letta 比较，将在上下文中的 core memory 对应到 AG 的工作角色，
archival retrieval 对应到 LTG，对话 recall 对应到证据。Mem0/Zep 提供提取／构图
比较。这些是工程类比，不是 NMG 验证、依赖，也不证明其他系统缺少来源／验证层。
[运行时文献对照](../session-active-graph-runtime-design.zh-CN.md#文献对照调查于-2026-09-01)
保留历史调查及证据限制。

### 边界说明

- AG 不精确等于 A-S 短期记忆或原始捕获缓冲。它是从暂定／持久含义及观察中选择
  的可变工作图，投影另行冻结。
- Cowan 的注意焦点观点及约四个 chunks 的容量，是原材料保留、未经核实的背景
  线索，不是 AG 上限。
- NMG 不可变 `HistoryRecord` 更接近情节来源 trace；STG/LTG 是语义解释。
  CLS 的遗忘／干扰描述是类比，不是测得的 NMG 行为。
- [提升与降级](../memory-graphs.zh-CN.md#提升与降级)拥有接纳阈值及来源要求。
  任何类比都不能覆盖这些条件。
