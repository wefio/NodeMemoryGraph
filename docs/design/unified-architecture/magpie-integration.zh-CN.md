## 边界与上游接口

Magpie 是模型网关边界上的额外集成候选，不是 Agent 执行器；客户端 Harness 继续拥有工具声明、执行和后续推理回合。此绑定可以为 Magpie 后面的客户端提供召回，不要求每个客户端都实现原生 NMG 插件，也不替代 pi durable 云端宿主。

[社区插件仓库](https://github.com/magpie-community/plugins#gateway-hooks)说明异步 Bun 网关 hook。[已发布宿主合同](https://github.com/yetone/magpie/blob/v0.1.1273/docs/subsystems/gateway-request-hooks.md)定义用于修改上下文的 `onRequest(body, ctx)`，以及有界、尽力而为的完成观察 `onResponse(reply, ctx)`。`ctx.state` 仅存活于一次请求，不是持久对话状态。网关拒绝 hook 修改工具、工具选择、模型或 stream 设置。实现时固定目标 Magpie 版本并核对合同；示例记忆插件不构成 NMG 兼容性证据。

异步 NMG 服务调用使用 `magpie.hooks` 包。同步网关 middleware 的运行环境不同，不能将它当成该服务客户端。[工具插件](https://github.com/magpie-community/plugins#tools-for-every-agent)通过 Magpie 的 MCP 服务暴露工具；客户端也可以直接连接 NMG MCP 端点。两种方式都不把执行所有权交给网关 hook。安装与发布是独立工作，本设计不交付它们。

## 能力划分

| 路径 | 目标能力 | 边界 |
| --- | --- | --- |
| 网关请求 hook | 有界自动召回与上下文注入 | 观察模型请求，不拥有完整 Harness 生命周期 |
| 完成 hook | 完整回复后的可选观察／采集 | 尽力通知，不是持久队列，也不证明使用过记忆 |
| Magpie 工具插件或 NMG MCP | 显式 search、精确 get 与受治理的 remember | 需要真实客户端工具连接和授权会话绑定 |
| 插件管理页 | 库统计、召回／搜索活动、token 账本、向量模型／key 设置及连接测试 | 使用共享管理接口，不另建记忆数据库、模型循环或任务调度器 |

在前提成立时，复用 NMG 的共享准入、查询归一化、预算及 Agent Surface 投影。绑定将支持的请求外壳转换为这些输入，只修改允许的上下文字段。Chat、Responses、Anthropic 和 Gemini 分别测试；不支持的外壳原样通过，不修改记忆。Magpie 能代理某协议不表示此绑定也支持该协议。

仅网关召回通过内部 search/get 后的共享证据投影，提供自足、有界且经过授权的上下文，不指示模型调用客户端没有连接的工具。只有精确 get 工具连接已确认时，才适合使用精简头部与后续读取 ID。保留工具调用／结果配对、角色边界和原始用户文本。召回证据是来源材料，不是新的用户指令。注入证据不证明模型使用或认可了它。

## 管理面板与互补观测

[管理面板与联动计划](magpie-operations.zh-CN.md)建议先借用 Magpie 的 GUI，再交付网关召回，负责统计口径、配置／key 归属、候选索引切换和交付切片。已有原生 NMG 插件的用户可先使用页面。NMG 提供库事实与记忆生命周期事件；Magpie 仅提供受支持接口暴露的网关观测，平台可见不等于 hook 可见，缺失数据保持未知。

原生绑定与网关贡献互补能力。逐绑定会话选择自动召回所有者，再通过验证过的关联身份组合可获得的观测。网关请求活动与完整 Harness 执行状态分别表达，并避免 NMG 后台模型请求递归触发网关召回。首版页面不要求重复工具或第二层协作系统。

## 身份、作用域与同意

使用宿主配置的认证端点：本地 daemon 或云端记忆服务。插件不打开 SQLite，不选择第二个后端，也不启停共享 daemon。保留[共享端点规则](harness-integration.zh-CN.md#宿主能力与端点选择)；远端失败不能将数据发送到无关本地存储。

Magpie 的 origin、agent、session 和工作目录元数据有助于准入和归因，但不能认证租户。模型名称和供应商账号不是记忆命名空间。只有端点凭证有效且作用域明确配置时，才准入请求。默认跳过非本地／未知来源；额外网关 key 或远程客户端需要明确授权和命名空间绑定。按目标版本重新验证，不能假定旧示例包含全部 origin 枚举。

缺少稳定 session ID 时，不能用模型名、当前目录或空键创建共享会话状态。此时只允许授权的无状态召回，或跳过集成。云端／本地会话 AG 写入、归因和需要调用 fence 的工具，只有获得可信的逐客户端／会话绑定后才启用。工具插件的通用 `execute(args)` 示例本身不证明它能取得原 Harness 会话；不能猜测某次 MCP 调用对应哪个并发网关请求。

召回与采集分别获得同意，采集默认关闭。即使只读召回，也会向所选服务发送查询；远程查询导出需要明确配置连接。仅发送操作所需的有界文本和来源，默认不发送完整历史、system 指令、隐藏推理、凭证或工具正文。设置／测试路径说明服务和作用域，不发送真实对话，也不写入记忆。

## 请求与完成行为

已准入请求在召回前选定原始租户／会话／端点绑定，提取有界查询，并将绑定保存在私有请求状态中供完成时使用。路由或设置变化后，不将完成结果解析到不同账号。权限撤回时停止采集，不切换目标继续发送。

区分用户回合准入、工具续接、辅助调用及推理重试。重复模型请求不一定代表新用户回合。只有宿主提供稳定身份，或绑定拥有经过验证的等价机制时，才能承诺回合级去重；仅靠文本哈希会合并用户合法重复输入。使用服务端状态续接的 Responses 请求需要明确验证；网关观察不到充分上下文时跳过注入，不虚构对话历史。

召回遵守网关截止时间和取消信号，限制响应字节，并对端点失败进行退避。超时、授权失败或记忆输出无效时，保持供应商请求不变，仅报告不含内容或凭证的固定状态。此失败行为用于可选自动召回；显式记忆工具返回真实错误，不将失败写入假装为成功。hook 不延迟或替换客户端已经收到的模型回复。

`onResponse` 可能报告不完整或失败回复，也可能在关闭时被丢弃，不是可靠持久采集机制。采集明确启用时，通过既有历史／导入配置保留获准来源证据；观察到文本不等于获得创建 Agent 确认语义事实的授权。响应成功不是正向反馈，也不确认召回陈述。导出前重新检查采集同意和原始作用域。

尽力采集只报告已确认接收，不承诺完整对话历史。不得盲目重试非幂等写入。无损采集需要另行设计带操作 ID 和重放证据的持久交接。宿主能够保存调用身份时，显式记忆工具遵循[外部效果合同](harness-integration.zh-CN.md#外部效果与恢复)；否则未明确的结果需要对账。

## 与原生适配器共存

每个 Harness 会话选择一个自动召回／采集所有者。使用原生 NMG 插件或 pi durable 绑定的客户端，可以将该会话排除在 Magpie hook 之外。两条路径必须并存时，共享可验证的披露键；两个独立进程内去重缓存并不足够。没有明确名称／所有权选择时，不通过 Magpie 和直接 NMG MCP 重复提供同一组工具。

网关能观察流量，不代表可宣告空闲唤醒、宿主交互命令、持久检查点或 NMG 任务协作。另行需要本地黑板访问时，必须有独立且受支持的客户端／会话合同；它不在首个 Magpie 记忆集成切片内。[能力矩阵](../harness-capability-matrix.zh-CN.md)只有在交付行为具备有范围证据后，才增加 Magpie 列。

## 验证与待实现工作

真实部署前使用模拟 NMG 服务和录制的协议样例。必要用例包括：

- 请求准入、身份缺失、租户／会话隔离、端点变化、撤回同意和远程来源显式启用。
- 每种受支持请求协议、用户／工具／辅助续接、重试身份、工具调用配对及不支持外壳原样通过。
- 已确认与未确认精确 get 工具连接时的有界授权召回；超时／取消／失败保持原请求。
- 流式完成、部分／失败回复、完成通知丢失，以及关闭采集时只读召回。
- 原生插件共存、重复请求、撤回重查及不推断正向反馈。
- 工具 schema 与 Agent Surface 一致、参数校验、真实 MCP 客户端／会话绑定及未明确写入结果。
- 插件重载、实际 Magpie／Bun 目标启动、配置的本地／云端连通性，以及测试设置时不导出对话。
- 按[面板验收切片](magpie-operations.zh-CN.md#交付顺序与验收)验证管理指标、时间段／重试分类、管理凭据处理与向量索引切换。

准确包布局、目标版本、origin／session 保证、协议支持子集和 MCP 会话映射仍待验证。本设计增加一个集成候选，不代表已安装插件或已交付能力。
