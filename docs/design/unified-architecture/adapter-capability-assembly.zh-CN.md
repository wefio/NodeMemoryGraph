# 声明驱动的适配器能力装配

[English](adapter-capability-assembly.md) · [术语](adapter-capability-assembly.terms.yaml)

**Status:** draft
**Authority:** [Harness 集成](harness-integration.zh-CN.md)

## 目的与范围

此候选方案让薄适配器通过提供可执行的宿主绑定和选择能力，获得共享 NMG 行为，
解决工具注册漏接、生命周期编排重复及适配器清单遗漏。它是设计提案，
不是当前插件加载合同，也没有新增运行时。名称与声明格式保留调整空间。

共享层已有工具／动作合同、Agent Surface、`SessionRecallFlow`、`RecallBudget`、
上下文准备及端点／会话绑定，但各宿主仍分别注册和编排部分行为。
其中 `HarnessConnection` 协商服务方法与能力，不负责装配宿主事件，也不会凭声明让宿主拥有上下文写入接口。

## 三层职责

| 所有者 | 声明与可执行职责 |
| --- | --- |
| NMG 共享能力 | 一份实现，定义所需端口、服务操作、生命周期语义、输出／预算规则及合同检查 |
| 宿主薄适配器 | 对实际实现的原生工具注册、回合准入、上下文投递、最终工具结果、完成与唤醒接口提供带版本的绑定 |
| 已绑定会话 | 根据宿主绑定及端点解析可用能力，再应用配置中的启用状态，按操作选择一个效果所有者 |

例如新增共享能力后，已有绑定满足要求的适配器应能获得该能力，不必再复制一份功能编排。
宿主缺少端口时仍需实现绑定，布尔声明本身不能产生原生 hook。

声明或配置变更可以激活已安装的实现。新增共享运行时代码仍需加载兼容版本，
只更新 daemon 的能力声明不会自动更新随包交付的 DSH 插件或已经运行的 OpenCode 插件。

| 示例能力 | 所需绑定形状 | 保留的语义区别 |
| --- | --- | --- |
| 显式记忆／状态工具 | 工具注册、认证端点与会话绑定 | 工具可用不等于自动上下文承载 |
| 自动召回 | 合适的准入信号、上下文插入与作用域绑定 | 网关请求不一定是新的用户回合 |
| 工作状态承载 | Owner 状态读取与完整正文的准入上下文路径 | 准备与最终投递不同 |
| 工具观察与答案归因 | 绑定后的最终结果／已提交答案事件 | 执行前提醒不是最终工具结果或声明见证 |
| 黑板投递 | 本地黑板访问与受支持的宿主入队 | 下一条 prompt 投递和空闲唤醒是不同能力 |

绑定可示意为 `tools.register`、`turn.admit`、`context.prepare`、`tool.result`、
`execution.end`。NMG 将既有共享流程挂到这些端口，发布解析后的工具／能力面。
这些名称只是示例，不是今天可调用的新 API。先使用小型绑定对象和普通函数，
不引入通用工作流引擎或另一套调度器。

## 根据实际装配解析行为

能力描述可以分别记录声明支持、装配完成、会话启用和验证证据。
缺绑定、版本不兼容、端点不可用或宿主关闭 hook 时，说明能力不可用的原因。
声明或装配完成不等于已经测试或启用。

共同检查服务声明的方法和宿主实际安装的绑定，在新会话代次或重连时重新解析。
描述符不授予认证、writer 权限或 hook 信任。例如，Codex 宿主支持插件，
与已经验证 NMG Codex hook 插件包是两件不同的事；NMG 交付缺口不是宿主限制。

保留既有提供方能力并集。原生插件、MCP、事件 hook、CLI 和 Magpie 可以贡献端口，
前提是可信映射能连接到同一获准会话／作用域。选择一个提供方不删除其他插件的完整实现。
映射无法建立时保留明确缺口，不静默共用 AG ID、重复效果，或把请求时通知描述为空闲唤醒。

## 清单、使用指引与检查

候选目录以可执行实现为依据，成为能力表和机器可读诊断的来源。
每个已交付入口注册描述符，由包／入口检查发现目录登记缺失。
生成的能力摘要链接到已有宿主操作说明和范围明确的验证证据。
安装命令及宿主特有注意项仍由各自 owner 维护，不能从能力名推断出来。

检查可覆盖缺少必需端口、服务方法不兼容、声明工具未出现在宿主目录、事件未激活、
取消／迟到准备、会话代次错误及提供方效果所有权重复。
真实宿主激活仍不同于描述符／类型验证。未登记适配器应成为清单错误，
不能因为作者忘记一列就从能力矩阵消失。

首个切片可以在 Pi、MCP 和 OpenCode 间共享显式工具注册，再逐步接准入／状态流程和其他宿主。
迁移期间保留现有适配器可用，行为移入装配前提供范围明确的等价性证据。
自动矩阵生成与装配运行时仍未实现，当前[使用指南](../../../skills/nmg-memory/references/adapter-usage.zh-CN.md)
描述的是实际接入路径。
