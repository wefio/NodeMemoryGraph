# 测试组合已有对象上的行为

[English](2026-10-12-deliverable-tests-compose-behavior.md)

**Status:** implemented
**Approved:** explicit

## 问题

Task Board 交付与保留期测试共同执行领取条目和提交产物，初始场景却不同：保留期测试在历史过期时刻之前执行动作，再推进到较晚时刻清理。始终创建新工作或自行读取时钟的工厂不能表达已有对象上的共同操作。

节点关系回归也共享已有节点上的相邻连边。跨消费者命名路径与回路意图有实际用途；准备工厂或默认无环的图抽象不能保留这些意图。

## 决策

`tests/support/task-board-behavior.ts` 导出普通类型化函数 `claimAndDeliver`。调用者传入已有 entry 引用（`taskId` 与 `id`）、行动身份、digest、租期和 `now`。函数领取该引用，再在同一指定时刻交付，返回实际交付快照；不创建条目或推定“最后一次结果”。

场景构造留在两个消费者本地。交付测试选择当前时间，保留期测试传入历史存活时刻。时钟注入仅覆盖组合的两个动作，不代表整个场景都可注入：创建条目和最终处理仍使用产品 API 自己的时钟。

两次写入不是原子事务。异常原样传播；领取成功后交付失败，领取仍可观察。该函数不含断言或前置条件过滤，这是此片段的选择，不是禁止算子包含判定的通用规则。需要观察两步之间的状态或单独验证拒绝动作时，测试直接调用 store API。

原断言、预期拒绝和字面量测试声明保留在调用处。已有节点路径使用 `tests/support/node-graph-behavior.ts` 的普通函数 `linkNodePath`，仅要求类型化的关系写入能力。核对过的基本路径共享它；元数据写入、evidence 合并判定、独立边与中间观察继续显式表达。行为与资源的分界由[测试运行时设计](../../design/ci-cd-and-quality.md#41-行为片段与资源-fixture)拥有。

## 考虑过的替代方案

- 保持文件内准备工厂。共同片段改用行为函数：两个真实消费者需要独立于创建与时钟选择的行为。
- 在共享函数内部读取时钟。不采用：历史保留期场景要求两个动作都使用调用者的时刻。
- 包装每次 API 调用。不采用：增加间接层，却没有命名共同的多步行为；不同的后续动作保持显式。
- 合并整个领取／交付／裁定流程。不采用：测试需要在中间状态观察或拒绝动作。
- 添加回滚或事务包装。不采用：这会改变失败语义，而不是组合既有 API。
- 引入 DSL、生成器或案例表声明。暂缓：一个共享片段不足以推出这些设施，RTM 发现仍要求字面量名称。
- 排序或去重路径端点、自动闭环，或与 memory chain 共用默认 DAG 限制。不采用：端点顺序、重复写入和节点关系回路属于消费者的原有意图。
- 用通用裁定替换原断言。不采用：复用不赋予重定义既有行为预期的权限。

## 后果

共享片段显式标出对象引用和时间边界，可以在其他动作之后重复作用于同一条目。它的契约测试使用隔离的内存 store，观察时钟、重复组合、冲突拒绝与部分失败；原有两个文件数据库生命周期不变。产品 API、依赖、验证 route 和验收标准不变。显式输入与辅助函数测试增加维护成本，本决策不主张行数收益或性能收益。

租约边界试验使用同一函数，不扩展其接口。具名场景在交付前观察 attempt 隔离，区分存活续租与到期后同身份重新领取，并验证接手改变产物角色，而不是永久排除旧身份。本轮不退役原测试：主动释放与租约到期是不同上下文，不能仅因最终字段相同就当成已证明的重复。

[第二轮试点记录](../../experiments/verification/behavior-composition-and-combinatorial-testing-2026-10-12.md#第二轮试点结果)与[边界组合试验](../../experiments/verification/behavior-composition-and-combinatorial-testing-2026-10-12.md#第三轮边界组合结果)拥有比较、目标运行和负控制的测量结果。这些证据只覆盖被测切片，不证明完整检出能力或完整正确性。[已有节点路径抽取结果](../../experiments/verification/behavior-composition-and-combinatorial-testing-2026-10-12.md#已有节点路径实施结果2026-10-13)拥有其保留对比、契约运行和限定故障结果。路径函数保留用于这些消费者；选定块在此收尾，不自动启动连续试点。

## 延后项

参数覆盖生成器、有预算的序列探索、全部动作的时钟注入与扩大迁移不属于本轮，也不是自动进入的下一轮试验。消费者需要观察片段内部时拆开片段，不隐藏观察或过滤预期拒绝来维持复用。
