# 稳定入口与局部上下文查找

[English](2026-09-16-stable-entry-local-context.md)

**Status:** implemented
**Approved:** explicit

## 问题

根入口重复开发命令，并承载适配器启动细节。开发流程要求每次编辑前调用路由，
文档维护要求即使已知拥有者也先读文档索引。这些必经跳转增加阅读和维护成本，
却不能证明 Agent 理解了真正适用的契约。

## 决策

[根入口](../../../AGENTS.md)拥有稳定查找协议。Agent 通过搜索、目录和清单发现
当前结构，再读取适用的局部说明、所属契约章节和确切实现。入口不维护模块清单
或可执行的环境配置说明。

[开发流程](../../../skills/repo-development/SKILL.md#before-editing)在所有权或
检查要求不清楚时使用 `agent:context`；验证与协作义务保留，直接查找不以路由
命令为前提。[文档维护流程](../../../skills/doc-maintenance/SKILL.md#content-that-can-be-read-locally)
拥有章节范围、条件链接和来源引用的维护规则。

操作说明在所属位置可发现：格式化和生成构建属于开发流程，链接式 profile 的
启动前提属于 [DSH 包 README](../../../dsh/dsh-nmg/README.md#启动前构建)。
隐藏功能登记的触发点进入开发流程，规则仍由既有决策拥有，事实仍由注册表拥有。

必要知识可从共享仓库或明确的共享任务引用恢复，不依赖本地索引、记忆或前任
Agent。本次不引入 harness 接入、上下文编译器、新任务存储或人工全仓地图。

## 考虑过的替代方案

- **根入口维护小型模块地图。** 不采用：它重复易变结构，增加同步义务。
- **强制路由命令或自动注入。** 不作为默认查找前提：普通搜索与文件读取必须可用，
  harness 修改不在任务范围内；保留既有路由作为辅助工具。
- **拆分所有文档或生成另一份摘要库。** 不采用：更多文件和派生文字可能增加跳转
  和漂移，本次只需要可独立读取的章节和既有拥有者。
- **精简入口时删除操作规则。** 不采用：迁移保留规则的适用触发点和包级启动前提。

## 后果

模块移动和命令变化不再要求改根入口。Agent 仍需选择相关章节，仓库文字无法强制
加载或移除已读上下文。链接与文档检查验证结构完整性，不证明语义充分性或真实
Agent 表现。

## 延后项

本次文档改动不包含新会话对照实验；查找调用、阅读量、遗漏约束和维护改动量仍需
独立测量。不声称任务成本或完成率已有实测改善。
