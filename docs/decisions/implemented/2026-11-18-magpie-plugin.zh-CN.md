# 将 Magpie 装配为独立的 NMG 适配器

[English](2026-11-18-magpie-plugin.md) · [术语](2026-11-18-magpie-plugin.terms.yaml)

**Status:** implemented
**Approved:** explicit

## 问题

各客户端的宿主 hook 不同，需要共用记忆接口。Magpie 能准备模型上下文并向客户端提供工具，但它的 MCP 执行上下文缺少路由会话状态所需的原生会话 ID。

## 决策

适配器通过共享 JSON 能力清单装配。Magpie 绑定声明中的工具、请求与完成 hook，并提供管理页。符合条件的网关请求通过密封会话句柄与插件工具关联。只连接工具的客户端可显式创建会话。每个网关 agent 可以把选定的操作交给其原生适配器。

状态、证据和黑板通知使用共享 InformationView 预算。黑板投递和自动召回归因以已进入请求的内容为准。配置、索引准备和批量检索计数归 daemon 管理。激活候选配置前，先测试向量连接，再准备完共享索引。项目索引继续按已有流程在需要时准备。

## 考虑过的替代方案

- 使用全局 MCP 会话。并发聊天会共享状态，精确记忆引用可能跨会话串用。
- 把存储和向量配置放进网关进程。其他管理端需要另配配置，插件重载也会接管持久工作。

## 后果

插件可以独立运行，也可以和原生适配器同时使用。独立的原生会话和 Magpie 会话各自持有状态。请求 hook 在模型请求时投递黑板通知，回复归因用于诊断。检索计数覆盖服务端尝试，进程突然退出可能丢失尚未落盘的一批数据。网关 token 来自 Magpie 聚合用量账本。

[安装指南](../../../magpie-plugin/README.zh-CN.md)提供打包和使用步骤。[私有宿主复现脚本](../../experiments/runtime/magpie-plugin-probe.mjs)在 Magpie 0.1.4338 下验证已安装包、八项 MCP 工具声明、两次 Chat Completions 请求、会话隔离、所有者状态承载和受保护的管理快照。模型使用本地模拟服务，付费调用为零。[管理接口测试](../../../tests/cli/operator.test.ts)使用本地模拟向量服务验证候选配置激活。
