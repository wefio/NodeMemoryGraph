# 每个 embedding 只持久化一份向量

[English](2026-10-07-single-vector-payload.md)

**Status:** implemented
**Approved:** auto

## Problem

同一向量同时以 JSON 和 Float32 BLOB 保存。检索虽然优先使用 BLOB，仍读取两列；
纯 FTS 查询还加载并解码最终不参与打分的向量。缩小 SQLite 页不能消除这些重复，
而且页内排布收益依赖具体数据。

## Decision

沿用现有二进制表示保存唯一实际载荷，JSON 列保留兼容占位。
迁移与读取语义由[存储契约](../../design/design.md)统一定义。
版本标记使完整迁移只在首次可写升级时执行；之后出现的旧 JSON 行仍可读取，
不为此在每次打开时重新扫描整个向量表。

保留解码器对二进制类型的判断，而非直接使用 `COALESCE`：SQLite 的 BLOB 类型亲和性
允许写入文本，类型错误时仍须回退到 JSON。Qwen 候选依据模型记录存在性，而非 JSON
内容。Float32 精度、打分、缓存归属、事务、证据及图关系/状态语义保持不变。

## Alternatives considered

- **长期保留两种格式。** 增加存储和序列化工作，但读取已经优先采用 Float32，
  并不提高检索保真度。
- **删除 JSON 列。** 需要重建表，并使仍查询两列、但已能读取二进制的旧读端失效。
- **删除一个 embedding 模型或改用 Float16。** 改变覆盖范围或精度，不是消除相同载荷的重复。
- **自动修改页大小或执行 vacuum。** 不能直接解决重复字节，还引入重建、剩余空间、
  WAL 和部署环境相关风险。

## Consequences

迁移 savepoint 在失败时回滚所有向量修改、新增列和版本标记，也支持调用者已有事务。
已有二进制字节、主键和时间戳保持不变；二进制形状不匹配声明维度时，保留未验证的旧文本。

[存储回归测试](../../../tests/core/store/vector-storage.test.ts)覆盖原子回滚、重复打开、
按模型读取/写入、旧格式回退，以及不读取向量载荷的中文/标点 FTS。
删除重复值减少逻辑存储，但已有数据库文件不一定立即缩小；物理压缩由单独受控的操作完成。
[受控存储实验](../../experiments/store/single-vector-payload-2026-10-07.md)在页大小不变时比较两个已压缩端点。

## Deferred

云端 bridge/WASM/VFS 兼容性及仅读取 JSON 的外部读端，需要取得源码并完成部署层测试后
再上线。真实云端体积、延迟、上传行为、备份恢复和页大小迁移，均不是本地合成测试能证明的。
本次仓库验证不迁移生产数据库。
