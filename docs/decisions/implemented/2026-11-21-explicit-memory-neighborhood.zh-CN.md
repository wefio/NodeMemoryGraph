# 通过显式搜索浏览记忆临域

[English](2026-11-21-explicit-memory-neighborhood.md) · [术语](2026-11-21-explicit-memory-neighborhood.terms.yaml)

**Status:** implemented
**Approved:** explicit

## 问题

精简召回的预览可能指向尚未展示的相关上下文。调用方需要用现成的引用继续查看这些记录。

## 决策

本地 search 将单独输入的完整记忆 ID 或调用方持有的复合短引用视为临域锚点。查询复用来源和
图索引，并遵循调用方的可见范围和检索上限。临域搜索生成自己的候选页，经济档预览预算用于初次召回。

## 考虑过的替代方案

在经济档直接装入邻居，会让它们在每次召回里和初始候选竞争预算。另设工具需要各宿主为相同的
候选预览注册第二个入口。

## 后果

检索结果已经携带可用的引用和作用图。复用这对字段可以沿用一个搜索工具，由调用方决定是否展开
临域。ID 通过索引定位，无需生成查询向量。[检索与显示契约](../../design/recall-context-and-display.zh-CN.md#浏览记忆临域)
定义了入口和结果。

普通显式检索使用经实测的 20 条预览页，并可在末尾两个位置补入匹配查询的相邻回合。
[预算回放](../../experiments/retrieval/explicit-search-budget-2026-11-21.zh-CN.md)记录证据和生产的来源约束。
