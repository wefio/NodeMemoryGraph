# 从当前记忆投影本地用户画像

[English](2026-11-21-local-user-profile.md) · [使用的术语](2026-11-21-local-user-profile.terms.yaml)

**Status:** implemented
**Approved:** explicit

## 问题

稳定的个人偏好能帮助处理相关请求。每轮提供完整画像会让无关条目占用上下文。

## 决策

本地画像从显式作用域内归属于用户的偏好与约束生成。原有记录维护归属、证据、
有效期、替代与撤回。画像条目命中触发词后进入自动召回，使用其候选与上下文预算。

## 考虑过的替代方案

独立维护的摘要需要跟踪每次更正和撤回。按需投影沿用原证据的生命周期。
每轮固定注入会持续占用上下文。

## 后果

画像选择在本地完成，无需单独的向量请求。调用方可通过显式作用域查看完整画像和维护源记录。
画像与证据通过共享的证据 ID 双向关联。

[召回契约](../../design/recall-context-and-display.zh-CN.md#用户画像)说明准入、渲染和维护入口。
