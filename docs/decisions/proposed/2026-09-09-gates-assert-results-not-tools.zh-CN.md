# 门只断言结果的性质，从不断言工具的身份

[English](2026-09-09-gates-assert-results-not-tools.md)

**Status:** proposed

## 问题

2026-09-09 的调研问的是：工具已经标准化、便捷了，Agent 为什么还在写一次性脚本。三条发现指向同一结论：

- **偏好是模型层面的。** 一项 17,000 次运行的工具选择研究中，OpenAI GPT-4o/Codex 家族的 Agent
  偏爱「写一段内联脚本处理文件」而不是用专门的工具，为此接受约两倍的 token 开销；
  Claude 家族偏爱 `ripgrep`（占搜索任务 68%），Cursor 偏爱 AST 查询。
- **奖励结构在鼓励它。** *The Tool-Overuse Illusion*（arXiv 2604.19749）表明模型对自己的能力
  边界存在「知识边界错觉」，并且**只看结果对错的奖励会主动增加多余的工具调用**（随训练步数
  最多上升 65%）；把奖励平衡后减少 66.7%/60.7%，准确率不降。
- **这是行业级的。** GitClear 的 2.11 亿行变更研究（2020–2024）显示：重构在变更行中的占比从
  25% 降到不足 10%，而复制粘贴（克隆）从 8.3% 升到 12.3%，**首次超过「移动」的代码**。

这个仓库里是同一个模式。`skills/doc-maintenance/SKILL.md` 第 48 行早就说状态会在散文里腐烂，
而 40 个设计文档里仍有 19 个带着自由文本状态。`AGENTS.md` 要求把 `npm run agent:context` 作为
任何改动的第一步；那个审计脚本用法的 session 一次都没跑过它。`nmg-rcp` 没有任何 npm 脚本、
任何 workflow 调用它，而一个 538 行的工具用手写方式组装了同一个库。

缓解手段的文献在机制上是一致的：*「你通过上下文窗口喂给 Agent 的一切，说到底都是建议」*，
以及*「能验证的 Agent 是好的，必须验证的 Agent 更好」*。**提醒不是机制。**

但显而易见的下一步——让验证器强制要求使用那个工具——是错的，三重错：它无法被检测（一次性脚本
和已提交脚本是同样的字节）；它禁止了正当的变化；而且**一个给自己的采用设门的验证器是自我认证**，
而这正是本仓库已经禁止的（`harness-cannot-self-certify`）。

## 提案

**门可以断言结果的性质，不得要求特定的工具、入口或文件。**

第一条这样的性质，也是真正能改变行为的机制：**同一个零件不得有两份实现。** 一个在两个文件里被
定义的辅助函数、统计函数、解析器或加载器就是错误，无论它住在哪个文件、叫什么名字。Agent 可以
用已有的零件满足它，可以把自己的新零件放到任何它喜欢的地方，也可以根本不需要那个零件——
**门不指定位置。**

推论：

- 验证器不得为自己的采用设门。RCP 的检查断言仓库的性质，不得要求 `nmg-rcp`。
- 一条只有一种满足方式的门，是伪装成性质的工具要求，需要单独决策。
- 依本规则新增的每一条门，都要在同一条决策里写明它的废除条件。

## 考虑过的替代方案

**在 Skill 里提醒 Agent。** 否决：这个实验本仓库已经做过两次——状态规则和 `agent:context`
规则——而缓解文献明确说上下文窗口里的指令只是建议。

**在验证器里要求使用工具。** 否决：无法检测、禁止变化、且自我认证。

**删掉没人用的入口。** 否决：砍掉的是产品表面，并不改变产生一次性脚本的行为。

**什么都不做。** 否决：GitClear 的数据表明这个趋势是全行业的，不会自我纠正。

**登记每个入口（`2026-09-09-register-every-entry-point`）。** 保留，但降级。它回答的是
「这是干什么的」，不是「它会不会被用」。它是文档，不是强制。

## 验收标准

- 重复检查在「同一个零件被定义两次」时失败，在「同一个零件只定义一次」时通过；`tests/` 覆盖两者。
- 失败信息中不出现任何 Agent 必须使用的文件、工具或入口。
- 没有一条 RCP 检查要求 `nmg-rcp`；检查断言的仍是仓库的性质。
- 本决策引用上述调研，使下一个读者不必重跑。

## 风险

- 函数体比较是近似的：改了名、又改了一行的副本能通过。接受：门是地板，不是证明。
- 对结果设门仍然强制了行为。这一点明写而不隐藏：强制的是仓库本就持有的性质（DRY），不是某个实现。
- 去重可以通过「把更差的那份提升为共用」来满足。接受：排序质量属于评审，没有门能做。

## 推迟

- 零件货架——让复用更便宜——是另一项改动，不是本决策的前置条件。
